# 🍱 BentoCraft Atelier (特製弁当工房)

เว็บแอปพลิเคชันจำลองการจัดชุดข้าวกล่องและเบนโตะแบบอินเทอร์แอกทีฟ (**Interactive Drag-and-Drop Bento Configurator**) พัฒนาด้วย **React 19 + TypeScript + Vite + Tailwind CSS** ออกแบบตามแนวคิด **Impeccable Craft UI** เพื่อช่วยให้ลูกค้าสามารถทดลองจับคู่เมนูอาหารคาว เครื่องเคียง ขนมหวาน และท็อปปิ้งลงในช่องข้าวกล่องด้วยตัวเอง พร้อมเห็นภาพตัวอย่างเสมือนจริงทันที

---

## ✨ ที่มาและเป้าหมายของโปรเจกต์ (Project Vision)

ในการรับทำข้าวกล่องจัดเลี้ยงหรือเบนโตะ ลูกค้ามักต้องการเห็นภาพตัวอย่างว่า *"ถ้าจับคู่เมนู A กับเมนู B และขนม C หน้าตาในกล่องจะออกมาเป็นอย่างไร?"* ซึ่งเดิมต้องเสียเวลาและวัตถุดิบในการทำอาหารจริงมาจัดถ่ายรูปเดโม่ให้ลูกค้าดูทุกครั้ง

**BentoCraft Atelier** จึงถูกสร้างขึ้นเพื่อแก้ปัญหานี้ โดยนำภาพถ่ายอาหารแต่ละเมนูมาแยกเป็นชิ้นส่วนสำหรับ **ลากวาง (Drag & Drop)** ลงในแม่พิมพ์กล่องข้าวรูปแบบต่างๆ ช่วยให้ลูกค้าจำลองหน้าตาข้าวกล่อง คำนวณงบประมาณ และส่งใบสรุปรายการสั่งทำได้ทันที

---

## 🚀 ฟีเจอร์หลัก (Key Features)

- **🖱️ ระบบลากวาง 2 รูปแบบ (Dual Drag & Drop + Click-to-Place)**
  - ลากการ์ดเมนูอาหารไปวางในช่องกล่องเบนโตะได้โดยตรง (รองรับการลากสลับช่องภายในกล่อง)
  - รองรับการคลิกเลือกเมนูแล้วแตะช่องเป้าหมาย สำหรับการใช้งานบนมือถือและแท็บเล็ต
  - ลากหมวด **ท็อปปิ้ง & ซอส** วางซ้อนทับบนช่องที่มีอาหารหลักอยู่แล้วได้
- **📷 โหมดแสดงผลภาพถ่ายอาหารเสมือนจริง (Photorealistic Studio View)**
  - สลับมุมมองได้ระหว่าง **มุมมองภาพถ่ายเต็มช่อง (Full-Compartment Photo View)** และ **มุมมองจัดจาน (Plated View)**
- **🍱 เลือกรูปทรงกล่องและวัสดุภาชนะได้หลากหลาย**
  - **รูปทรงกล่อง (Vessel Geometry)**: กล่อง 4 ช่องมาตรฐาน, กล่องมาคุโนะอุจิ 5 ช่องพรีเมียม, กล่องเฮลตี้ 3 ช่อง
  - **วัสดุกล่อง (Craft Finish)**: ไม้สนฮิโนกิ (`Hinoki Wood`), ลงรักคุโระขอบทอง (`Kuro Urushi`), เซรามิกชิการากิ (`Shigaraki Ceramic`)
- **📊 คำนวณโภชนาการและสมดุลสีอาหาร 5 สี (Real-Time Telemetry & Washoku 五色)**
  - คำนวณแคลอรีรวม (`kcal`), โปรตีน (`g`), คาร์โบไฮเดรต (`g`), ไขมัน (`g`) และราคารวมต่อกล่องแบบเรียลไทม์
  - วิเคราะห์ความสมดุลของสีอาหาร 5 สี (แดง, เขียว, เหลือง, ขาว, ดำ)
- **🎁 โหมดคาดสายโอบิปิดฝากล่อง & ใบสรุปรายการสั่งทำ**
  - จำลองการปิดฝากล่องพร้อมพิมพ์ชื่อชุดข้าวกล่องบนสายคาด และออกใบสรุปรายการอาหารพร้อมยอดชำระสุทธิ

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

- **Frontend Framework**: React 19 + TypeScript
- **Build Tool**: Vite 7
- **Styling**: Tailwind CSS 3 + PostCSS
- **Design System**: Impeccable Craft UI ([DESIGN.md](./DESIGN.md) & [PRODUCT.md](./PRODUCT.md))

## 💻 วิธีติดตั้งและรันโปรเจกต์ (Getting Started)

### วิธีที่ 1: เปิดดูทันทีโดยไม่ต้องรันเซิร์ฟเวอร์ (Quick Standalone Preview)
สามารถดับเบิลคลิกเปิดไฟล์ **`preview-standalone.html`** บนเว็บเบราว์เซอร์ (Chrome, Edge, Safari) เพื่อทดลองใช้งานได้ทันที

### วิธีที่ 2: รันผ่าน Vite Development Server
1. ติดตั้ง Dependencies:
   ```bash
   npm install
   ```
2. รันเซิร์ฟเวอร์สำหรับพัฒนา:
   ```bash
   npm run dev
   ```
3. สร้างไฟล์สำหรับใช้งานจริง (Production Build):
   ```bash
   npm run build
   ```
